# Portefølje

Min personlige portefølje med skills, speciale, elektronik og cykler.

**[Åbn siden live](https://sebastiandammeyer.github.io/portefolio_web/)**

**[Prøv spillet: kør rundt på kloden](https://sebastiandammeyer.github.io/portefolio_web/prototype/spil.html)**
Kør min long john rundt på en lille klode med piletaster, eller klik på et hus eller en prik på radaren. Gå ind i husene og se kataloget på tavlen. (Prototype, tekster er udkast.)

Siden er ren HTML, hostet på GitHub Pages. Forsiden er `index.html`, og spillet er `prototype/spil.html` (bygget med Three.js).
